План тренировок

Профиль · Конструктор плана

Шаблон → сетка упражнений по дням → N тренировок в общий календарь

Структура · шаблон = название + тег-цели (общая форма / ГТО-норматив / произвольная) + сетка упражнений по дням + «сгенерировать N тренировок» (§4.16).
Данные · упражнения и объёмы — пример, наполняется методистом. Ячейки сетки — включить/исключить день упражнения из шаблона.
Календарь · «Пересадить в календарь» выгружает сетку (N тренировок) в общее расписание — механика как в ГТО (§4.14).
