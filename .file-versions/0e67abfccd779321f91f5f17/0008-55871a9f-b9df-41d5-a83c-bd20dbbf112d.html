03Цвета и свотчи · перенесено

Семантические токены цвета: категории событий, статусы, ГТО и рейтинг, виды спорта. Базовые цвета — в ЭТАПЕ 1. Значения читаются напрямую из assets/ds.css.

Цвет события — не декор, а семантика типа. Полоса слева и цвет --c задаются токеном типа события:

  • --type-training — тренировка (личная · с тренером · групповая · онлайн)
  • --type-event — глобальное событие СП, заводит админ (чемпионаты, челленджи)
  • --type-rental — аренда площадки (создаю я, зовут друзья)
  • --type-club — клубное событие (клубы — сообщества по видам спорта)

09Выбор: карточка, радио, чекбоксы, переключатель · перенесено

Карточка выбора .pick-card — тизер/аватар + заголовок + подпись + кружок выбора. Используется для выбора роли («Я спортсмен») и типа события (тренировка · событие · аренда · клуб). Цвет типа — через --c (токены --type-*). Выбор — настоящий <input>, состояние через :checked; для статичных макетов — класс .is-on. Вариант .is-check — квадрат с галочкой. Отдельно: радио .radio, чекбокс .check, переключатель .switch.
